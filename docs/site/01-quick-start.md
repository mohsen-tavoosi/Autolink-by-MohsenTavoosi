افزونه Autolink by MohsenTavoosi لینک داخلی رو موقع نمایش صفحه می سازه. به متن ذخیره شده پست ها و به دیتابیس دست نمی زنه. یعنی خاموشش کنید، همه لینک ها از صفحه ها محو میشن!

قبل از شروع، اگر قوانین کلی این کار رو نمی دونید، اول [آموزش لینک سازی داخلی خودکار برای هر سایت](https://mohsentavoosi.com/automate-internal-links) رو ببینید. اینجا فقط اجرا روی وردپرس رو می گم.

## افزونه رو چطوری نصب کنم؟

1. در پیشخوان وردپرس به بخش افزونه ها و افزودن برید.
2. نام Autolink by MohsenTavoosi رو جستجو کنید، یا فایل زیپ رو آپلود کنید.
3. فعالش کنید. منوی Internal Links کنار منوهای دیگه پیدا میشه.

اگر قبلا نسخه قدیمی افزونه رو داشتید، پیش از هر کاری از بخش Import / Export خروجی JSON بگیرید. جدول و رکوردهای فعلی دست نمی خورند، ولی بکاپ هیچ وقت اضافه نیست.

## اولین رکورد رو چطوری بسازم؟

رکورد یعنی یک آدرس مقصد و تا 20 کلمه کلیدی که همه به همون آدرس لینک میشن. در بخش Keywords & Links روی Add New Record بزنید و این فیلدها رو پر کنید:

- Keywords. هر خط یک کلمه کلیدی. همه شکل های یک نیت رو بنویسید، مثل "درب اتوماتیک"، "خرید درب اتوماتیک" و "انواع درب اتوماتیک". ترتیب خطوط مهمه، چون تیک Smart link diversity از این ترتیب استفاده می کنه.
- Link URL. آدرس کامل با http یا https، یا مسیری که با یک اسلش شروع میشه، مثل /my-page.
- Max links per page. پیش فرض 1 هست. همه شکل های کلمه کلیدی این رکورد با هم شمرده میشن.
- Max links per paragraph. عدد 0 یعنی بدون سقف.
- Only on these pages. برای تست، فقط یک صفحه رو انتخاب کنید.

یادتون باشه هر آدرس فقط در یک رکورد میاد و هر کلمه کلیدی هم فقط در یک رکورد. کلمه کلیدی تکراری خطا میده، چون یک کلمه کلیدی فقط مال یک صفحه هست!

## چطوری ببینم لینک ساخته شده؟

صفحه رو باز کنید و View Source بگیرید. Inspect نه، چون Inspect چیزی رو نشون میده که جاوااسکریپت بعد از لود عوضش کرده. اگر تفاوتش رو نمی دونید، [تفاوت DOM و Source](https://mohsentavoosi.com/video/dom-vs-source/) رو ببینید.

اگر کش صفحه یا CDN دارید، اول پاکش کنید. کش همون HTML قدیمی رو نگه می داره.

## اگر چیزی خراب شد چکار کنم؟

تیک Enabled رو در General Settings بردارید. همه لینک ها فورا از صفحه ها میرن و رکوردهاتون سر جاشون می مونن. بعد از رفع مشکل دوباره روشنش کنید.

## بعدش کجا برم؟

- همه تنظیمات رو در [مرجع تنظیمات افزونه](https://mohsentavoosi.com/wordpress-auto-internal-links/settings) توضیح دادم.
- اگر لینکی نیومد، [چرا لینک ساخته نمیشه](https://mohsentavoosi.com/wordpress-auto-internal-links/troubleshooting) رو ببینید.
