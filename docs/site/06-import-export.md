همه رکوردها و تنظیمات افزونه رو می تونید در قالب یک فایل JSON ببرید بیرون و روی سایت دیگه یا همین سایت برگردونید. این هم بکاپ هست، هم راه جابه جایی سایت، هم راهی که AI بتونه رکوردها رو بخونه و برای شما بسازه.

## چه موقع Export بگیرم؟

- قبل از به روزرسانی افزونه.
- قبل از هر Import با حالت Replace.
- قبل از تغییر دسته جمعی رکوردها.
- قبل از روشن کردن تیک حذف داده در On uninstall.

در بخش Import / Export روی Export All Records (JSON) بزنید.

## Import چطوری کار می کنه؟

فایل JSON ساخته شده با همین افزونه رو انتخاب کنید (حداکثر 1 مگابایت). فایل هایی که با اسم قدیمی افزونه (Auto Internal Links) خروجی گرفتند هم قبول میشن. دو حالت دارید:

- Merge. رکوردهای فایل به رکوردهای فعلی اضافه میشن.
- Replace. همه رکوردهای فعلی پاک میشن و فایل جایگزین میشه. دکمه اش قبل از اجرا تایید می خواد.

نکته مهم اینه که کل فایل پیش از هر حذفی بررسی میشه. اگر فایل خراب باشه، هیچ چیز عوض نمیشه!

## چرا بعضی رکوردها رد میشن؟

بعد از Import گزارشی میاد که تعداد رکوردهای رد شده رو با دلیلش می گه:

- Invalid. رکورد کلمه کلیدی یا آدرس ندارد یا آدرسش مجاز نیست.
- Duplicate URL. این آدرس در یک رکورد دیگه هست. هر آدرس فقط یک رکورد داره.
- Duplicate keyword. این کلمه کلیدی مال رکورد دیگه ای هست. یک کلمه کلیدی فقط مال یک صفحه هست.

اگر تیک نیم فاصله روشن باشه، دو کلمه کلیدی که فقط در فاصله و نیم فاصله فرق دارند تکراری حساب میشن. در رکوردهای موجود چیزی حذف نمیشه.

## می تونم فایل رو به AI بدم؟

بله. فایل JSON ساده هست و AI می تونه بخونه و رکوردهای تازه بسازه. ولی خروجی رو قبل از Import خودتون ببینید و روی یک صفحه تست کنید. شاخص ها رو شما تعیین می کنید، AI فقط سریع تر اجرا می کنه. روش ساخت رکورد درست رو در [آموزش کیورد تارگتینگ](https://mohsentavoosi.com/video/keyword-targeting-film/) گفتم.
